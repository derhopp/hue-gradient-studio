## Hue Gradient Studio 0.1.0

First HACS release of Hue Gradient Studio.

- Supports Philips/Signify ZHA lights, with four independent three-color presets per lamp.
- Provides a bundled Lovelace editor with color pickers and multi-light selection.
- Includes independent timed preset switching per light.
- Supports Home Assistant actions for scripts and automations.
- Provides setup using **Settings → Devices & services → Add integration**.
- Registers a versioned JavaScript module for storage-mode dashboards.
