## Hue Gradient Studio 0.1.2 — English and German localization

- The dashboard editor follows the Home Assistant user's language: German for `de*`, English for `en*`.
- Other interface languages fall back to English; no other languages are bundled.
- Localizes dashboard controls, presets, color-picker labels, helper text, confirmations, validation and status messages.
- Adds localized Home Assistant action names, descriptions and field labels to the English and German translation catalogs.
- Preserves all per-light presets, colors, custom preset names and automations.
- Updates UI localization tests for both languages and the English fallback.

Install using HACS and restart Home Assistant. Refresh the dashboard to update its JavaScript resources.
